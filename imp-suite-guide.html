1. IMP — Intention Market Protocol

IMP (Intention Market Protocol)

Open standard so AI agents can say “I need X” and tools can say “I provide X” in a machine-readable way.

  • Defines how capabilities, intentions, and matches are described
  • Lets anyone self-host a matcher (not locked to SML)
  • Feeds badges, radar, receipts, drops, and ranking

$0 forever — protocol, schemas, reference code. We never charge to “use IMP.”

Without a shared language, every agent integration is custom glue. IMP is the common tongue.

Not another closed agent marketplace. Open protocol first — commerce layer optional.

Upgrade from “hope the LLM guesses your API docs” → structured intention ↔ capability matching.

Any time someone says “is this proprietary?” → “Protocol is free and open. Hosted Index is optional.”
